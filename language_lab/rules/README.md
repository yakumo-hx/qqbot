# rules — 「像人说话」规则提取

本目录把群聊语料蒸馏成**可测量、可回测**的说话规则，供后续生成/评测使用。
只做规则，不发送消息、不改动机器人。

## 为什么单独一个目录

- 规则提取有自己的**数据子集纪律**和**回测口径**，与原始语料、风格卡分开；
- 产出物可版本化（`rules_v1.*`），后续 `rules_v2` 可以并行比较。

## 数据子集（重要）

只使用 **LLBot / recorder / capture 来源、2026-10-24 起** 的干净子集：

- 机器人日志在 10-24 之前**没有媒体字段、没有 uid**；混入会把「媒体率 0%」「句尾不加标点 90%」当成规则；
- 干净子集当前约 **5,798 条人类消息**（有文本 4,679 条）。

## 规则分层

| 层 | 内容 | 本版 |
|---|---|---|
| A 形式 | 长度、标点、emoji、媒体、引用、@ | A1–A3 |
| B 节奏 | 连发、回复延迟 | A4–A5 |
| C 语用 | 何时接、接什么类型 | 未做（需要标注） |
| D 反面 | 机器人账号对照、回避形式 | D1–D2 |

## 产出

| 文件 | 说明 |
|---|---|
| `rules_v1.json` | 机器可读：每条规则的值、样本量、置信度、稳定性 |
| `rules_v1.md` | 人读报告（含回测表） |
| `rules_v1_prompt.txt` | 给生成器的紧凑提示词（10 行以内） |
| `validation.json` | 训练/测试跨天漂移明细 |
| `extract_rules.py` | 提取脚本（读语料 → 上述文件） |

## 运行

```powershell

```

前置：规范语料已刷新（`python -m language_lab ingest`）。

## 回测方法

- 训练：10-24 ~ 10-27；测试：10-28 ~ 10-30；
- 指标漂移 >20% 的规则降级为 `medium` 并写进 `note`；
- 下版新增规则时沿用同一口径，避免用未来数据调参。

## 已知局限

- 只有 11 天、单群；话题偏军事/游戏/日常；
- 媒体只有占位符，只能学「发图频率」，学不到「发什么图」；
- 本机 bot 自己的回复不在语料里（recorder 不记录出站消息），负样本是群里另外几个角色扮演 bot；
- 规则只覆盖「怎么说」，不覆盖「说什么」——内容与幽默靠检索示例，不写规则。
